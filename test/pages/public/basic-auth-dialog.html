Browser login dialog

Opens Firefox's own login dialog (HTTP authentication), for example to take a screenshot.

Open the login dialog

Dummy login if you want to sign in: basic-user / Dummy-Basic-Pass.

To see Firefox's dialog unchanged, turn off Answer the browser's own login dialog with KeePass in the KeePassHttp-Link settings (Read from KeePass tab). With it on, the extension may answer the dialog for you.

Firefox shows the dialog again on the next visit only after it forgets the login: open the page in a new private window, or clear the site data for localhost.
