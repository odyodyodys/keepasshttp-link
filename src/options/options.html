General Settings

To fill username and password into the focused form, press Alt + Shift + U. To fill only the password, press Alt + Shift + P. You can change these shortcuts in about:addons → gear icon → Manage Extension Shortcuts.

Adds an icon to every password field to generate a new password. KeePass generates it with its profile for new entries.

When KeePass returns exactly one login, fill it into the detected fields without asking.
Show a list of the available logins under every username field.
KeePassHttp-Neo needs the KeePassHttp plugin in KeePass. It is tested with KeePassHttp 2.3.1.0 from github.com/alan-null/keepasshttp.

Advanced settings

Attention! Change these settings only if you know what you are doing.

KeePassHttp-Neo talks to KeePassHttp on http://localhost:[port]. KeePass must run on this computer: remote KeePass hosts are not supported, because the connection is plain HTTP. If the default port is in use, change it in the KeePassHttp options and set the same port here.

Must be the same as in the KeePassHttp options. Range 1025 to 65535. Default: 19455
Do not show warnings and errors as page alerts.
Cut filled values to the maximum length the page allows. This can cause problems when a site lowers the limit after you created a password, or when the password in KeePass is longer than the limit.
